# 0020 ข้อความสรุปกระชับ: ตัดวงเล็บขยายความ แยกรายชื่อจังหวัดและความหมายระดับไว้ต่างหาก

Status: accepted (2026-11-23, ผู้ใช้สั่งในแชต "ตามที่เสนอเลย เริ่มทำได้" หลังตรวจผลสรุปแล้วเห็นว่ายาวเกินไป) · แก้ส่วนของ ADR 0013 (ค่าคำนวณ "ราว N ใน 10" และการแทรกนิยามในบรรทัด) · ข้อกำหนดของ CLAUDE.md ที่ว่าฉบับแสดงเดิม 35 ฉบับต้องเหมือนเดิมทุกไบต์ไม่ใช้กับการเปลี่ยนนี้ (ตั้งใจเปลี่ยนข้อความ)

Context: ข้อความที่แม่แบบสร้าง (พยากรณ์รายวัน 7 วัน และพื้นที่ทะเลของเดินเรือ) ยาวเพราะคำขยาย: "(ราว 2 ใน 10 ส่วนของพื้นที่ภาค)", "(คือ อุณหภูมิ 16.0-22.9 องศาเซลเซียส)", หน่วยซ้ำ "นอต (กม./ชม.)", คำนำ "ลมพัดจากทิศ… ความเร็ว…" และรายชื่อจังหวัดยาว ผู้อ่านต้องการเนื้อหาตรงประเด็น

Decision:
- ตัวเลขทุกตัวในข้อความยังมาจากบล็อกต้นฉบับของภาคนั้นเท่านั้น ไม่มีค่าคำนวณในข้อความอีก (เลิกใช้ "ราว N ใน 10 ส่วน" และข้อยกเว้น F1 ข้อ ก ของ ADR 0013; ฟิลด์ `rain_area_tenths_*` และ `derived_formula` ไม่ถูกสร้างแล้ว) · "ร้อยละ N ของพื้นที่" ยังเป็นสัดส่วนพื้นที่ ห้ามเขียนเป็นโอกาส
- รูปแบบ: ฝน "ฝนฟ้าคะนอง ร้อยละ 20 ของพื้นที่ · ลมกระโชกแรงบางแห่ง", อุณหภูมิ "อากาศเย็น · ต่ำสุด 20-25 °C · สูงสุด 30-35 °C", ลม "ตะวันออกเฉียงใต้ 10-15 กม./ชม." (เดินเรือแสดงนอตอย่างเดียว ค่า กม./ชม. ยังอยู่ใน `facts`), คลื่น "คลื่นสูงราว 1 ม. · ที่ฝนฟ้าคะนอง สูงกว่า 2 ม."
- `SummaryLine.detail` (รายการข้อความ) เก็บรายชื่อจังหวัดที่เคยอยู่ท้ายประโยคฝน หน้าเว็บแสดงเป็นบรรทัดรองและพับเหลือ 2 บรรทัด กด "ดูทั้งหมด" ได้ (ชื่อจังหวัดไม่หาย)
- `SummaryLine.notes` เก็บความหมายระดับฝน/ความหนาวตามหมายเหตุ TMD (ข้อ ข ของ F1 ยังใช้: ตัวเลขในนิยามมาจากอภิธาน) หน้าเว็บรวมไว้ในกล่องพับเดียวต่อหน้า "ความหมายระดับฝนและอากาศ (ตามหมายเหตุของ TMD)" แทนการแทรกทุกบรรทัด
- ตัวตรวจ: F1 ตรวจเฉพาะ `text` กับบล็อกต้นฉบับ · F2 ตรวจจังหวัดใน `text` และ `detail` · ใหม่: ทุกรายการใน `notes` ต้องตรงอภิธานตามคำใน `facts.glossary_terms`
- ไม่เปลี่ยน: ประกาศเตือนภัย สรุปรายสัปดาห์ ภาพรวมและคำแนะนำของเดินเรือ และโหมดทั่วไป ใช้ข้อความต้นฉบับคำต่อคำอยู่แล้ว ไม่ผ่านแม่แบบ

Consequences: สัญญา SummaryLine เพิ่มสองฟิลด์เสริม (ค่าเริ่มต้นว่าง ไฟล์เก่าอ่านได้) ต้องส่งออก schema ใหม่ golden file และข้อมูลใน `data/processed/` เปลี่ยนทั้งชุด ต้อง `npm run load:neon` ให้เว็บจริงเปลี่ยน
